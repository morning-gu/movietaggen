# 440 三模态宇宙 + A 预测迁移 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实验数据集从 1,035 部改为 440 部三模态宇宙（与 A 协议 v3 对齐），测试分割固定为 A 的 88 部清单，direct_score 基线改为迁移 A 的 v3-full 实跑预测。

**Architecture:** 宇宙过滤与基线来源均为配置项（`data.universe` / `baselines.direct_score_source`）；`eval/protocol.py` 新增 `fixed_split`（读 `processed/eval_test.txt`）与 `sample_limited_movie_ids`（受限跑统一从训练池抽样），替换全部时序拟合分割接线（05 校准、07 genre/bert、direct_score own_run few-shot）；report 层新增"固定测试/固定训练"子集行兑现同集可比。

**Tech Stack:** Python 3.12 + pandas/pyarrow（无新依赖）

**Spec:** `docs/superpowers/specs/2026-10-21-440-universe-design.md`（已批准，b8601fd）

## Global Constraints

- 语言约定：注释/文档中文，代码标识符英文（沿用 A/B/C）
- 消融即配置：宇宙与基线来源是配置项，任何论文要消融的变量不改代码即可切换
- 防泄露：所有拟合面（校准/few-shot/genre 统计/BERT 训练集）仅用 train = 440 − 88 = 352 部，逐接线 `assert_no_leakage` 收尾
- 自包含：运行时零依赖 A 仓库（迁移物物理入库 + sha256/PROVENANCE）
- 冒烟全绿：smoke.yaml 钉 `direct_score_source: own_run`，`universe` 过滤对 synthetic 为 no-op
- 前置（控制器在 Task 1 前执行，非子代理任务）：服务器取回 `results/v3-full/annotations.parquet` → `data/processed/direct_score_a.parquet`；复制 A 本地仓库 `data/processed/eval_test.txt` → B `data/processed/eval_test.txt`（两文件就位后 Task 1 才可开工）

## Review Focus

1. **a_borrow parquet 与宇宙错配**（陈旧清单/电影不在 440 内）→ 加载器大声失败而非静默出空表——Task 6 测试钉
2. **eval_test.txt 坏输入**（文件缺失/空文件/非整数行/88 ⊄ dataset）→ `fixed_split` ValueError 点名文件与行——Task 3 测试钉
3. **movie_limit ≥ 训练池**（如 limit 400 > 352）→ 退化为全训练池而非崩溃/空集——Task 3 测试钉
4. **固定分割泄露**（few-shot/genre/bert 拟合面与 88 测试集交集非空）→ assert_no_leakage 触发——Task 5/6/7 测试钉
5. **synthetic + a_borrow 误配**（冒烟/合成路径读到不存在的迁移 parquet）→ 配置校验拦截——Task 2 测试钉
